# 保証人のきまり（hosho-kimari）

口約束でも保証人？連帯保証だと何がちがう？保証人が2人なら？友だちや家族の借金の保証人になる場面を見て、民法の決まりどおりの答え（責任・まず本人に・何人か・根保証・事業の借金）を選ぶ1日5問の学習ゲーム。正解したら「これは、どの決まり？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/hosho-kimari/>

- 答えは、e-Gov 法令検索の民法（<https://laws.e-gov.go.jp/law/129AC0000000089>）の保証債務の条文（第446〜465条の10。2026年11月17日に読みました）で確かめたことだけです。
